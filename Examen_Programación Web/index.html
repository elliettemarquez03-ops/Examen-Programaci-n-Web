CSS3, Flexbox y CSS Grid Layout

Aprende las bases para crear sitios web flexibles y adaptables.

1. Fundamentos de CSS3

CSS3 es el lenguaje utilizado para definir la presentación y el diseño visual de un documento HTML.

  • Sintaxis: Seleccionadores, propiedades y valores.
  • Modelo de Caja (Box Model): Content, Padding, Border y Margin.
  • Unidades de medida: Relativas (rem, em, %) y Absolutas (px).

2. Flexbox (Diseño Unidimensional)

Flexbox está optimizado para alinear elementos en una sola dimensión (en fila o en columna).

.contenedor-flex {
  display: flex;
  justify-content: space-between; 
  align-items: center;            
  flex-direction: row;           
}

Significado:

  • justify-content: Alinea elementos en el eje principal.
  • align-items: Alinea elementos en el eje transversal.
  • flex-grow y flex-shrink: Controlan el crecimiento y reducción de los ítems.

3. CSS Grid Layout (Diseño Bidimensional)

CSS Grid permite crear maquetas bidimensionales complejas organizando el contenido en filas y columnas simultáneamente.

.contenedor-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

Significado:

  • grid-template-columns y grid-template-rows: Definen la estructura de la cuadrícula.
  • gap: Define el espacio entre filas y columnas.
  • grid-column / grid-row: Controlan la posición de un elemento en la red.
